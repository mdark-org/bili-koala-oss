### Bental
https://bental.dev/
Bental 把一个完整的 PPT 编辑器、演示器，全部塞进一个 560KB 的 HTML 文件里，浏览器打开就能用，无需安装软件或粗测账号。它内置 Morph 变形动画、自研图表引擎，还支持 AES、GCM 端到端加密写作。密约存储在本地，从不上传服务器，文档本身是明文 JSON，Agent 可以直接编辑。Koala 认为，Bental 很好地展示了单个 HTML 文件结合浏览器能力，完全可以胜任很多本地化的使用场景。完成需求的同时，还能提供很好的隐私保护与离线体验。

### Openship
https://openship.org/
Openship 是一个开元的部署平台，覆盖从代码推送到生产环境的完整流程，自动识别 Node、Python、Go、Rust 等技术栈。一键配置 PostgreSQL、Redis 等服务，自动处理 SSL 证书和路由，每次部署都是不可变快照，支持零停机回滚。既可以用官方云服务按量付费，也可以在自己的虚拟机上完全免费自托管，还提供 CLI、Web 面板和 MCP 代理等多种操作方式。

### Retental
https://retental.com/
Retental 是一个开源 CLI 工具，把你的私有代码库，转换为可分享、可验证的技术能力通行证。它通过终端或 GitHub 应用连接项目，自动分析代码，来检测开发者的真实能力，让用户用自己的表述为作品打辩，最终形成可累积的能力档案。对 NDA 项目也友好，只暴露必要的信息。Koala 认为，这个产品瞄准的是 AI 原生时代的招聘信任问题。当简历和学费越来越难验证真实技能，用已交付的真实项目做背书，是个合理方向，尤其适合没有传统学历但有实战作品的开发者。不过挑战也很明显，凭证的价值取决于雇主是否认可这套体系。而 AI 大量参与写代码之后，代码分析能否区分个人贡献也是个未解的问题。

### Topcoat
https://topcoat.rs/
Topcoat 是 Tokyo 团队推出的 Rust 全栈框架，主打功能完备和生产力优先。服务器直接渲染一步组件，数据库查询、内线其中，省掉独立 API 层，客户端交互用信号系统实现。同一份 Rust 代码既跑在服务器，又编译成 JavaScript，完全不需要复杂的 Webpack 文件，还集成了 Tailwind 组件库和基于文件结构的自动路由。Koala 认为，Rust 做 Web 后端已经成熟，但全栈体验一直是短板。Topcoat 背靠 Tokyo 这个 Rust 异步生态的核心团队，路线上更接近 Rails 的一体化哲学，而不是 Leptos 那种 WebAssembly 优先的思路。不过项目还处于早期实验阶段。

### Databasement
https://databasement.dev/
Databasement 是一个数据库备份管理外宾用，把 MySQL、PostgreSQL、MongoDB、Redis 等八种数据库的备份，集中到一处管理，支持定时备份、自定义保留策略。备份可以存到 S3 等远端，还支持跨服务器恢复。它支持 SSH 隧道访问私网数据库，失败时通过 Slack、Telegram 等渠道告警。带容器部署，内置 Rest API 和 MCP 服务，方便 AI 助手接入。Koala 认为，数据库备份是每个团队都要做，但很少做好的事，常见状态是散落在各处的 Cron 脚本，坏了没人知道。Databasement 更为产品化，多数据库加多存储后端的覆盖面，在同类开元工具里算全的。MCP 接口也体现了对 AI 运维趋势的敏感。

### OpenCLI
https://opencli.com/
OpenCLI 是一个开元平整代理网关，专门解决 Agent 拿的明文 API Key 到处跑的安全问题。它的做法是让 Agent 的所有出栈请求都走这个网关，平整在网关层，按请求注入。Agent 的手里永远只有占位符，拿不到真实密约。策略在网络层强制执行，可以按端点封禁，按分钟、小时、天做限流，给敏感操作加人工审批，按项目隔离可访问的平整。Koala 认为，Agent 安全在过去一年最大的共识，就是靠 Prompt 约束模型行为根本靠不住，规则必须放到模型管不到的地方去执行。OpenCLI 选择的是网络层拦截这个位置，比在 MCP Server 里做全线校验覆盖面更广。因为 Agent 的写代码直接发 HTTP 请求这跳路也被堵住了，但局限也在这里，所有流量走一个代理，网关本身就成了单点。
